Panduan Wiring Komponen | Versi 1.0 | Mei 2026

1. Deskripsi Sistem

Dokumen ini berisi panduan lengkap untuk merakit komponen Indoor Smart Greenhouse menggunakan mikrokontroler ESP32. Sistem ini terdiri dari sensor suhu/kelembapan (DHT11/DHT22), relay module untuk kontrol pompa, dan koneksi WiFi ke cloud Supabase.

3. Tabel Wiring Detail

3.1 ESP32 - Relay Module (Kontrol Pompa)

ESP32 Pin Pin Relay Warna Kabel Fungsi
GPIO 5 (D5) IN / SIG / S KUNING Signal kontrol relay (ON/OFF)
3.3V / 5V VCC / (+) MERAH Power supply relay module
GND GND / (-) HITAM Ground bersama
Perhatian - Tegangan Relay
Jika relay module 5V, gunakan pin VIN (5V) ESP32. Jika relay 3.3V, gunakan pin 3.3V ESP32. Periksa label pada relay module sebelum menyambung.

3.2 ESP32 - DHT11 Sensor (Suhu & Kelembapan)

ESP32 Pin Pin DHT Warna Kabel Fungsi
GPIO 4 (D4) DATA / OUT HIJAU Data signal sensor
3.3V VCC (+) MERAH Power supply sensor
GND GND (-) HITAM Ground bersama
Catatan - DHT Sensor
Jika menggunakan DHT11/DHT22 versi module (3 pin), pull-up resistor sudah onboard. Jika menggunakan sensor raw (4 pin), tambahkan resistor 10k Ohm antara pin VCC dan DATA.

3.3 ESP32 - Power Supply

ESP32 Pin Power Supply Warna Kabel Fungsi
5V / VIN 5V Output (+) MERAH Power ESP32 via external supply
GND Ground (-) HITAM Ground bersama system
Micro USB USB Charger 5V 2A - Alternatif: Power via USB cable

3.4 Relay - Pompa Air (High Power Circuit)

Relay Output Koneksi Ke Warna Kabel Kondisi
COM (Common) Power Supply (+) MERAH Power source masuk
NO (Normally Open) Pompa VCC (+) MERAH Pompa nyala saat relay aktif
NC (Normally Closed) - - Tidak digunakan
WARNING - High Voltage Isolation
Pompa air menggunakan arus lebih besar dari ESP32. Jangan supply pompa dari pin ESP32! Gunakan power supply terpisah untuk pompa. Relay hanya berfungsi sebagai electronic switch.

6. Catatan Penting & Safety

6.1 Relay Power Configuration

Tipe Relay VCC Pin ESP32 Keterangan
Relay 3.3V Pin 3.3V Langsung ke pin 3.3V ESP32
Relay 5V (low trigger) Pin VIN / 5V Gunakan VIN jika ESP32 di-power via USB/5V

6.2 Common Ground Requirement

WAJIB - Common Ground
Semua komponen dalam sistem HARUS memiliki ground (GND) yang sama/bersama. Hubungkan GND ESP32, GND Relay, GND Sensor, dan GND Pompa ke titik ground bersama. Tanpa common ground, signal digital tidak akan berfungsi dengan benar.

6.3 DHT Sensor - Pull-up Resistor

Jenis DHT Resistor Keterangan
DHT11 Module (3 pin) Tidak perlu Resistor 10k Ohm sudah onboard PCB
DHT11 Raw (4 pin) 10k Ohm Tambahkan antara VCC dan DATA pin
DHT22/AM2302 Module Tidak perlu Resistor sudah onboard PCB

6.4 Pompa Power - Isolation

Isolasi Power Pompa
  • JANGAN supply pompa dari pin 3.3V atau 5V ESP32!
  • Pompa butuh arus lebih besar (500mA - 2A)
  • Gunakan power supply terpisah untuk pompa
  • Relay hanya sebagai switch, bukan power source

6.5 Safety & Deployment

Aspek Rekomendasi
Waterproofing Pasang elektronik dalam enclosure anti air. Jangan biarkan water splash ke PCB ESP32.
WiFi Range Pastikan ESP32 dalam jangkauan WiFi. Jika jauh, gunakan WiFi extender.
Sensor Position Jangan taruh DHT terlalu dekat pompa atau ESP32 yang panas. Data jadi tidak akurat.
Cable Management Gunakan kabel tie atau cable duct untuk merapikan wiring. Hindari kabel tersangkut.
Fuse Protection Tambahkan fuse untuk proteksi arus berlebih pada circuit pompa.

7. Setup Software & Upload

7.1 Library Arduino IDE (Wajib Di-install)

No Nama Library Author Install Via

Cara Install Library
Buka Arduino IDE > Sketch > Include Library > Manage Libraries. Ketik nama library di search box, lalu klik Install.

7.2 Board ESP32 Setup

  1. Buka Arduino IDE
  2. File > Preferences > Additional Board Manager URLs
  3. Tambahkan: https://dl.espressif.com/dl/package_esp32_index.json
  4. Tools > Board > Boards Manager
  5. Cari "ESP32" dan install "ESP32 by Espressif Systems"
  6. Tools > Board > ESP32 Arduino > ESP32 Dev Module

7.3 Langkah Upload Code

Langkah Aksi Keterangan
1 Hubungkan ESP32 ke PC via USB Pastikan driver CH340/CP210x terinstall
2 Buka file smart_greenhouse.ino Di Arduino IDE
3 Isi konfigurasi WiFi & Supabase SSID, Password, URL, API Key
4 Pilih Port: Tools > Port > COMx Cek Device Manager untuk port yang benar
5 Klik tombol Upload (panah kanan) Tunggu sampai "Done uploading"
6 Buka Serial Monitor (Ctrl+Shift+M) Baudrate: 115200

9. Troubleshooting

Masalah Penyebab Umum Solusi
ESP32 tidak terdeteksi di Arduino IDE Driver belum install Install driver CH340 atau CP210x sesuai chip USB-to-Serial ESP32
Upload failed / timeout Boot mode salah Tekan tombol BOOT pada ESP32 saat upload dimulai
WiFi tidak connect SSID/Password salah Periksa spelling case-sensitive. Pastikan WiFi 2.4GHz (bukan 5GHz)
HTTP Error 400/404 URL Supabase salah Pastikan URL format: https://xxx.supabase.co (bukan dashboard URL)
DHT read failed Wiring salah / sensor rusak Cek wiring DATA->GPIO4, VCC->3.3V, GND->GND. Coba ganti sensor
Relay tidak nyala Active level salah Ganti RELAY_ACTIVE_HIGH: false -> true atau sebaliknya
Pompa tidak nyala Power pompa tidak cukup Pastikan power supply pompa cukup besar. Jangan dari ESP32 pin
