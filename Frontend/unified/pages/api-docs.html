Verdanist API Documentation

Welcome to the Verdanist API. Our RESTful API enables developers to integrate smart greenhouse management capabilities into their applications, automate irrigation systems, and retrieve real-time sensor data.

Quick Start

# Install the Verdanist SDK
npm install @verdanist/sdk

# Or use cURL for direct API calls
curl -H "Authorization: Bearer YOUR_API_KEY" \\
  https://api.verdanist.io/v1/sensors/current

Authentication

All API requests require authentication using an API key. Include your API key in the Authorization header of each request.

API Key Header

Authorization: Bearer {your_api_key}

Example Request

const response = await fetch('https://api.verdanist.io/v1/sensors', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();

Base URL

All API requests should be made to the following base URL:

PRODUCTION
https://api.verdanist.io/v1

Sensor Data

GET /sensors/current

Retrieve current sensor readings from all active zones.

// Response
{
  "status": "success",
  "data": {
    "timestamp": "2026-04-30T12:00:00Z",
    "zones": [
      {
        "id": "zone_a",
        "name": "Indoor Hydroponics",
        "temperature": 24.5,
        "humidity": 68,
        "soil_moisture": 45,
        "light_level": 850
      }
    ]
  }
}
POST /sensors/history

Retrieve historical sensor data with filtering options.

// Request Body
{
  "zone_id": "zone_a",
  "start_date": "2026-04-01",
  "end_date": "2026-04-30",
  "metrics": ["temperature", "humidity"],
  "interval": "hourly"
}

Irrigation Control

POST /irrigation/trigger

Manually trigger irrigation for a specific zone.

// Request Body
{
  "zone_id": "zone_a",
  "duration": 300,
  "mode": "manual"
}

// Response
{
  "status": "success",
  "message": "Irrigation triggered",
  "job_id": "irr_1234567890",
  "estimated_completion": "2026-04-30T12:05:00Z"
}

Zone Management

GET /zones

List all configured zones with their settings.

POST /zones

Create a new zone with specified configuration.

PUT /zones/{zone_id}

Update zone configuration and thresholds.

Error Handling

The API returns standard HTTP status codes. Error responses include a descriptive message and error code.

Code Status Description
200 OK Request successful
400 Bad Request Invalid parameters
401 Unauthorized Invalid or missing API key
404 Not Found Resource not found
500 Server Error Internal server error
